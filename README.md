# Itay Portfolio

A product-focused cybersecurity portfolio for an Advanced SOC Analyst who builds practical security automation.

## Stack

- React 19
- TypeScript
- Vite
- Tailwind CSS v4
- React Router
- Motion
- Lucide React

## Start locally

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Validation

```bash
npm run lint
npm run build
npm audit
```

## Current routes

- `/` — Home
- `/resume` — Browser-readable resume
- `/projects/ioc-workbench` — IOC Workbench case study

## Codex workflow

Read [`CODEX.md`](./CODEX.md) before making changes. Keep prompts narrow and review every visual change in the browser before committing.
