# CODEX.md

## Project

This repository contains a premium personal portfolio for an Advanced SOC Analyst.

The portfolio should feel like a modern cybersecurity SaaS product rather than a traditional developer portfolio.

## Core Principles

- Keep the design clean and minimal.
- Prioritize readability and usability.
- Preserve visual consistency.
- Build reusable components.
- Prefer simple solutions over clever ones.

## Design Rules

- Never redesign existing sections unless explicitly requested.
- Keep all content inside the shared centered container.
- Maintain generous spacing.
- Avoid unnecessary animations.
- Avoid heavy shadows and excessive visual effects.
- Do not use perspective, rotation or skew unless explicitly requested.

## Code Rules

- Use React + TypeScript.
- Use Tailwind CSS.
- Keep components small and reusable.
- Avoid duplicated code.
- Avoid unnecessary dependencies.
- Follow the existing project structure.

## Before Every Task

1. Read this file.
2. Inspect the existing implementation.
3. Make only the requested changes.
4. Avoid unrelated refactoring.
5. Preserve the current design language.
6. Run lint and build if changes affect the application.

## Communication

If a request is unclear, ask for clarification.

If a better implementation exists, explain it briefly before implementing.

Never make large architectural or design changes without approval.
